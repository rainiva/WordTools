## 简介
本指南面向首次接触 WordTools 的用户，帮助你在本地快速完成安装与验证，并掌握“批量图片插入”等核心功能的使用方法。WordTools 是一个基于 COM 加载项的 Word 插件，在 Word 功能区新增“Word工具箱”选项卡，提供批量图片插入、自动编号与描述行等实用能力。

## 系统要求与验证
- 操作系统：Windows 7 或更高版本
- 应用软件：Microsoft Office 2010 或更高版本（Word）
- 运行时：.NET Framework 4.8
- 权限：安装与注册需管理员权限

建议在安装前确认：
- 已安装 .NET Framework 4.8
- 已安装 Visual Studio 或 Build Tools（用于构建）
- 已具备管理员权限（用于注册 COM 组件）

## 通过 Visual Studio 直接运行
步骤要点：
1. 打开解决方案文件
2. 选择 Debug 或 Release 配置
3. 按 F5 启动调试（会自动注册插件）
4. 或者先生成解决方案，再进行手动注册

该方式会自动执行构建与注册流程，适合快速体验与开发调试。

## 手动注册方法
步骤要点：
1. 先在 Visual Studio 中编译项目，生成 WordTools.dll
2. 以管理员身份运行命令提示符
3. 执行 regasm 命令注册 COM 组件
4. 在 Word 中启用加载项

该方式适用于生产部署与离线环境，便于精确控制注册过程。

## 验证安装成功
安装完成后，按以下步骤验证：
1. 完全关闭 Microsoft Word（包括后台进程）
2. 重新启动 Word
3. 在 Word 中打开“文件 → 选项 → 加载项”
4. 在底部“管理”下拉菜单选择“COM 加载项”，点击“转到...”
5. 勾选“Word工具箱”，点击“确定”

验证成功后，Word 顶部将出现“Word工具箱”选项卡，包含“图片工具”和“帮助”两个分组。

## 基本使用示例：批量图片插入
使用步骤：
1. 在 Word 中新建或打开一个文档
2. 点击“Word工具箱”选项卡中的“批量插图”按钮
3. 在弹出的“批量插图工具”窗口中：
   - 选择图片文件夹或直接选择多个图片文件
   - 设置图片高度（单位：厘米，留空表示不限制）
   - 选择描述方式：手动、无、文件名
   - 选择是否包含根目录与子目录图片
   - 选择是否启用自动编号及编号对齐方式
4. 点击“插入文件夹”或“选择文件”开始批量插入
5. 插入过程中会显示进度条，完成后自动调整图片尺寸并可选添加描述行

## 常见问题排查
- 无法找到 MSBuild
  - 现象：构建脚本报错，提示未找到 MSBuild
  - 解决：安装 Visual Studio 2022 Community 或 Build Tools for Visual Studio 2022
- regasm.exe 不存在
  - 现象：手动注册时报错找不到 regasm.exe
  - 解决：确认 .NET Framework 4.0 路径存在；或使用 PowerShell 脚本进行注册
- 以非管理员身份运行
  - 现象：注册失败并提示权限不足
  - 解决：右键以管理员身份运行批处理或 PowerShell 脚本
- Word 未显示插件选项卡
  - 现象：Word 启动后看不到“Word工具箱”选项卡
  - 解决：完全关闭 Word 后重启；在“文件 → 选项 → 加载项”中启用 COM 加载项

## 故障排除指南
- 卸载插件
  - 方法一：以管理员身份运行命令提示符，执行反注册命令
  - 方法二：在 Word 中通过“文件 → 选项 → 加载项”管理 COM 加载项，取消勾选“WordTools”
- 安装包部署
  - 使用 Inno Setup 脚本生成安装包，安装时自动注册 COM 组件并写入注册表项
  - 卸载时自动反注册 COM 组件
